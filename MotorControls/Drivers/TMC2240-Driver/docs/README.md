# Documentation Index

This directory contains complete technical documentation for the TMC2240 stepper driver and the STM32 implementation.

- **[Datasheet_TMC2240.pdf](Datasheet_TMC2240.pdf)**: Official Analog Devices / Trinamic TMC2240 Datasheet (Rev 2).
- **[API_Reference.md](API_Reference.md)**: Checked API overview, units, ownership, and explicit startup. Headers and the canonical driver README contain the authoritative contracts.
- **[Hardware_Guide.md](Hardware_Guide.md)**: Hardware connections, MKS module pinouts, motor coil connections, and dual-motor setups.
- **[Audit_and_Fix_Log.md](Audit_and_Fix_Log.md)**: Historical remediation record, not current release or hardware qualification evidence.
- **[Dual_Motor_and_Encoder_Config.md](Dual_Motor_and_Encoder_Config.md)**: Pinout design for dual TMC2240 and dual AS5600 I2C magnetic encoders on STM32F446RE.
